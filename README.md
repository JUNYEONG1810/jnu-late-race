# 포크레이트 — 9시까지 공대 2호관으로!

**포크레이트**(포크레인 + late)는 전남대 캠퍼스를 굴착기로 달리는 지각 레이스입니다. (저장소 이름·주소는 그대로 jnu-late-race)

전남대학교 광주캠퍼스를 3D로 옮겨 놓고, 미니 굴착기를 타고 돌아다니는 브라우저 게임입니다.
수업 과제 "GitHub에서 찾아본 오픈소스로 흥미로운 프로그램 만들기"로 만들었습니다.

**플레이:** https://junyeong1810.github.io/jnu-late-race/
(노트북·데스크톱 브라우저, 키보드 조작. 휴대폰은 지원하지 않습니다.)

## 게임 소개

- **자유 주행:** 정문에서 출발해 캠퍼스를 마음대로 달립니다. 건물에 가까이 가면 건물 이름이 뜨고, 오른쪽 위 미니맵에 내 위치가 보입니다.
- **지각 모드:** 교수님이 "9시까지 공대 2호관으로 와요."라고 말하면, 3분 안에 미션 장소 네 곳을 들른 뒤 공과대 2호관 강의실에 도착해야 합니다. 시간 안에 오면 A+, 늦으면 F.

## 조작법

| 키 | 동작 |
|---|---|
| ↑ ↓ ← → / W A S D | 운전 |
| Space | 브레이크 · 드리프트 |
| Shift | 부스터 (게이지 사용) |
| E | 미션 (표시 원 안에서 멈춘 뒤) |
| C | 시점 바꾸기 (뒤 / 위 / 운전석) |
| L | 지각 모드 시작 |
| M | 소리 켜기 · 끄기 |
| Esc | 지각 모드 일시정지 · 연출 건너뛰기 |
| 클릭 · Space | 연출 대사 넘기기 |

## 지각 모드

1. 카메라가 공과대 2호관 입구로 날아가고, 교수님이 걸어 나와 말풍선과 목소리로 대사를 합니다.
2. 정문의 굴착기를 앞·옆·뒤로 돌며 보여 준 뒤 3, 2, 1, GO!
3. 미션 장소(바닥의 빛나는 원)에 멈추고 E를 누르면 2초 진행 막대 뒤에 미션 완료, 부스터 게이지 50% 보충.
   - 농생대 1호관 🍠 고구마 수확 → 중앙도서관 📚 연체된 책 반납 → 제1학생회관 ☕ 아이스 아메리카노 주문 → 생활관 9호관 💻 두고 온 노트북 챙기기
4. 마지막으로 공과대 2호관 🏫에 도착하면 교수님이 판정합니다.

## 사용한 오픈소스와 데이터

- [three.js](https://threejs.org) (MIT 라이선스): 3D 렌더링
- 지도 데이터 © [OpenStreetMap 기여자](https://www.openstreetmap.org/copyright) (ODbL): 캠퍼스 경계, 건물, 도로, 녹지
- 3D 캠퍼스 아이디어: SMASH 대학교([hong-iron.github.io/SMASH](https://hong-iron.github.io/SMASH/))에서 영감 (코드는 가져오지 않고 새로 작성)
- 소리·목소리는 Web Audio API로 직접 합성 (소리 파일 없음)

## 만든 방법

- **지도:** `scripts/fetch_osm.py`가 Overpass API로 전남대 캠퍼스 경계(OSM way 105125653)와 주변 건물·도로·녹지를 받고, `scripts/build_map.py`가 캠퍼스 중심 기준 미터 좌표의 `data/campus.json`으로 바꿉니다 (Python 표준 라이브러리만 사용).
- **3D:** 빌드 없는 정적 사이트. three.js r160을 CDN + import map으로 불러오고, 건물·도로·녹지는 종류마다 메시 하나로 합쳐 그립니다. 창문 텍스처, 나무, 캐릭터, 굴착기는 모두 코드로 만든 도형입니다.
- **주행:** 물리 엔진 없이 직접 만든 아케이드 주행(가속·브레이크·조향·드리프트·부스터)과, 차를 원 하나로 보는 건물 충돌.
- **소리:** 엔진 "두두두", 궤도 "철컥", 부스터 터보, 미션 효과음, 대사마다 음절 단위로 합성하는 꿍싯꿍싯 목소리.
- **배포:** GitHub Pages (`main` 브랜치 루트).
- Claude Code와 함께 제작했습니다. 단계별 기록은 `제작로그.md`에 있습니다.

### 로컬에서 실행

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다 (JSON을 fetch로 읽기 때문에 파일을 더블클릭해서는 열리지 않습니다).
