# 참고 조사 (국토지리정보원 정사영상·수치지도)

게임에는 사진을 넣지 않고 판단 결과(위치·폭·색·층수·종류)만 쓴다. 잘라낸 사진은 `ref/`(커밋 안 함), 원자료는 `data/raw/ngii/`(커밋 안 함).
