# 데이터 근거 요약 (밤샘 14단계 기준)

게임에 들어간 캠퍼스 자료가 어디서 왔고 얼마나 믿을 만한지 한 장으로 정리했다. 자세한 내용은 각 문서에 있다.
근거가 없는 값은 기본값으로 두고 "근거 없음"으로 적었다. 본 것처럼 쓰지 않았다.

## 지도 (OpenStreetMap, ODbL)

- 캠퍼스 경계(OSM way 105125653) + 둘레 50m 안의 건물 352동(캠퍼스 안 210동), 도로, 녹지, 물, 주차장, 소품(벤치 26·자전거 보관소 18·버스정류장 18), 기념물 27곳.
- 화면 구석에 항상 "지도 데이터 © OpenStreetMap 기여자". 사진 모드·결과 이미지에도 같이 찍힌다.

## 건물 층수 (캠퍼스 안 210동, `data/building-floors.csv` 출처 칸)

| 출처 | 동 수 | 믿음 정도 |
|---|---|---|
| 수치지도 (국토지리정보원) | 90 | 확실 (공공 측량 자료의 층수 속성) |
| 브이월드 지상층수 (국토교통부) | 17 | 확실 |
| 브이월드 일괄값 ("전남대학교" 4층) | 23 | 추정 (대표값) |
| OSM building:levels | 37 | 추정 (기여자 입력) |
| 직접 (대학본부 9층) | 1 | 사람이 확인해 적음 |
| 없음 → 기본 4층 | 42 | **근거 없음** |

- 항공사진 원본 시차로 44동 층수를 "준확실(항공사진 원본)"으로 바꿈(`data/building-styles.json`, 밤샘 5단계). 검증: 수치지도 층수 건물에서 잰 높이와 게임 높이 차 중앙값 −0.6m, 평균 절대 차 2.7m.
- 항공사진으로 벽이 안 보인 82동은 그대로 두었다. 21동은 높이를 재지 못하고 보류했다(`docs/항공사진-보강.md`).

- "임의"는 시각적 다양성을 위해 고른 값이고, 실제 건물과 같다는 근거가 없다는 뜻이다.
- "확실(사진)"은 위키미디어 공용의 자유 라이선스 사진에서 건물을 알아보고(표지판·GPS) 확인한 것이다. 사진 자체는 게임에 넣지 않았다.

## 지형·물

- 지형: 국토지리정보원 수치지도(2020 1:1,000, 2025 1:5,000)의 등고선·표고점·옹벽으로 만든 5m 격자. 캠퍼스 바깥은 AWS Terrain Tiles(ETOPO1 NOAA, GMTED2010·SRTM USGS)를 쓴다. 정문 앞 출발점이 0m(해발 32.1m)이다. 차도 위 단차는 `scripts/smooth_road_terrain.py`로 정리했다.
- 용지 수면(밤샘 9단계): 수치지도에는 물 높이가 없어 물 안쪽 땅이 −0.1~5.4m로 기울어 있었다. 불러올 때 물 안쪽 격자점을 물가 높이의 아래쪽 1/4값(1.14m) 하나로 평평하게 한다. **실제 수위 근거 없음.** 보기 좋게 맞춘 값이다.
- 잔디: 정사영상(2025, 25cm)에서 판단한 2m 칸 4,876개(`data/lawns.json`).
- 차도 폭: 수치지도·정사영상으로 잰 74개 도로(`data/road-widths.json`). 나머지는 종류별 기본 폭이다.

## 기념물 (27곳, `data/monuments.json`)

- 준확실(정사영상·태그) 22, 확실(사진) 1, 근거 없음 4. 형태는 비석·조형물·흉상 등 11가지 단순한 모양이다. 인물 모양은 매끈한 덩어리로만 만들었다.
- 5·18 관련 기념물·인물상 둘레 45m 안에는 장난스러운 요소를 두지 않았다. 오리·고양이·동물 학생 경로·도장·무작위 사건(60m)이 여기에 해당한다. 부딪혀도 조용히 멈춘다.

## 게임에서 지어낸 것 (근거 없음, 놀이용)

- 미션 장소 위치(가장 가까운 차도 위 점), 타임어택 코스, 축구장 골대, 무작위 사건 자리.
- 산책하는 교수님의 경로, 오리·고양이·동물 학생의 자리와 경로.
- 셔틀버스 순환 경로(차도 그래프에서 고른 2km 안팎 고리. 실제 노선이 아니다).
- 밤 창문 불빛, 계절 나무 색, 가로등 자리(OSM에 없어 약 30m 간격).

## 출처 표기 (크레딧)

three.js, OpenStreetMap 기여자(ODbL), 국토지리정보원(지형·정사영상·수치지도·항공사진), Terrain Tiles(ETOPO1 NOAA, GMTED2010·SRTM USGS), 국토교통부 브이월드(건물 층수), SMASH 대학교(3D 캠퍼스 아이디어에서 영감, 코드 재사용 없음), Black Han Sans(키 아트 제목 글꼴, SIL OFL). 소리·음악은 모두 Web Audio로 직접 합성했다.
