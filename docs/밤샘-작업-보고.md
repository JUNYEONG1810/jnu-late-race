## 하지 못한 것·한계와 이유

- **실제 fps 측정:** 위와 같은 이유로 못 했다. 추정값을 측정값처럼 쓰지 않았다.
- **드리프트 점수:** 굴착기 주행은 옆으로 미끄러지지 않는다(Space는 더 날카롭게 도는 방식). 그래서 점수 = 도는 빠르기 × 속도로 했다. 조작감을 바꾸지 않으려고 물리는 손대지 않았다.
- **용지 수면:** 지형 자료에 물 높이가 없다. 그래서 물 안쪽 땅을 물가 높이의 아래쪽 1/4값 하나로 고르게 했다(근거 없음, 보기용).
  - 물가 둑이 5m 격자 삼각형 모양으로 울퉁불퉁하게 보이는 곳이 남아 있다. 물빛 대신 흙빛으로 칠해 덜 어색하게만 했다.
- **산책 교수님:** 성능 때문에 메시 1개 대역을 쓴다. 날개 손짓이나 표정은 지각 모드에서만 나온다.
- **고스트:** 일반 지각 모드의 A+ 최고 기록만 저장한다. 오늘의 도전은 날마다 순서가 달라서 뺐다.
- **무작위 사건:** 막힌 길 옆 잔디로 70% 속도로 돌아갈 수 있다. 일부러 막지 않았다.
- **시간대:** 색만 바꾸고 해 방향(그림자)은 그대로다. 밤에 가로등이 켜지지 않는다(조명을 더하지 않는다는 규칙).
- **대표 캡처:** `docs/captures/밤샘-*.jpg` 7장은 게임 3D 화면만 담았다(HUD 없음).
- **키 아트:** 구도는 night-6과 같다. 지금 게임 코드로 다시 렌더링만 했다.

## 아침 확인 순서 (추천)

로컬에서 확인한다(GitHub Pages는 main만 배포한다).

```bash
git switch night
python -m http.server 8000
```

1. **night-14(마지막) 먼저:** 노트북 Chrome 전체 화면, `http://localhost:8000/?fps=1`.
   1. 첫 화면 → 꾸미기 → 칭호.
   2. 자유 주행: 품질 "낮음"과 "높음"에서 fps를 확인한다.
   3. T·Y·P·Q·G, E로 내려 걷기(고양이·벤치·동물 학생·용지 풍덩), 대운동장 축구.
   4. 지각 모드 한 판 A+(첫 A+ 엔딩), 일부러 F(사유서), "이미지로 저장".
2. **night-3 확인:** 지형이 크게 바뀐 단계다. `git switch --detach night-3` 뒤 새로고침한다.
   - 정문 → 공대 2호관 → 용지 쪽을 달려 보며 땅·차도 단차와 fps를 본다.
   - 확인한 뒤 `git switch night`으로 돌아온다.
3. night-14가 느리거나 이상하면 단계를 낮춰 본다.
   - night-7: 지각 모드 재미까지만.
   - night-4: 꾸밈까지만.
   - 가벼운 모드 스위치로 장식만 끄고 볼 수도 있다.
4. 마음에 드는 단계를 정한다. main에 합치는 것은 직접 해야 한다. 예: `git switch main` → `git merge night-N` → `git push`, force는 쓰지 않는다.
