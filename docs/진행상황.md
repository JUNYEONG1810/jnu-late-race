- [D] 정문 대문: 정사영상(ref/gate_zoom.png)으로 실제 정문 확인 — 진입로를 가로지르는 짙은 회색 가로 루버(보 6~7개) 지붕 두 덩어리(동쪽 약 17m, 서쪽 약 8m) + 흰 사각 틀 기둥. 위치는 OSM 정문 점보다 62m 북쪽 (24, 446) → 이전 조사 결과 맞음, 정문·출발 위치(남쪽 25m)·연출 함께 옮김. 위에서 본 사진뿐이라 높이(7m 추정)·글자는 확인 못 해 글자는 뺌.

- [E] 주요 건물 14동(생활관 9A~9D 따로, 용봉탑 주변 = 용봉관·민주마루): data/building-styles.json. 정사영상 조각 ref/e/<이름>.png. 덩어리 나누기(교육융합관 고층부·저층부·유리 아트리움, 중앙도서관 원형 저층부·지붕 원형 단, 대학본부 원통+판상, 제1학생마루 본동·금속지붕 홀·옥상데크, 민주마루 홀, 농생대 1호관 경사지붕 현관동), 인문대 1호관 붉은 우진각 지붕 3동, 진리관·용봉관 옥탑. 층수는 바꾸지 않음(생활관 9A·9B·9D 15층·9C 9층은 사진의 기울어 보이는 길이와도 맞음, 대학본부는 OSM 4층 / 수치지도 9층 → 사진 근거 부족으로 4층 유지).
