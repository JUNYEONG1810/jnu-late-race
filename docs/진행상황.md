## 건너뛴 것과 이유

- 브이월드 3D 실사 텍스처 캡처(ref/vworld3d/<건물>/): 캠퍼스에 실사 텍스처 3D 건물이 없어 건너뜀 → 정사영상 근거 간이 방식.
- Mapillary: .env에 토큰 없음.
- ref/photos/: 폴더 없음.
- 정문 글자·높이: 위에서 본 사진뿐이라 확인 못 함 → 글자 없음, 높이 7m 추정.
- ㄱ자 우진각 지붕(생활과학대학 등): 회전 사각형 하나로만 우진각을 만들어서 지원 안 함 → 평지붕 + 지붕색.
- 대학본부 층수: OSM 4층 / 수치지도 9층으로 다르지만 사진으로 가릴 근거 부족 → 지금 값(4층) 유지.

## 성능 확인 (실제로는 78동째·174동째·마지막 세 번)

- [E2] 160동 뒤: 높음 10.9ms / 낮음 7.7ms. 마지막(196동): 높음 10.7ms / 낮음 7.3ms, 정문 출발 fps 60.
- [E] 14동 + [E2] 64동 뒤(78동): 정문 출발 장면 그리기 시간 높음 10.3~11.8ms / 낮음 7.5ms (지형 단계 9.4 / 8.3ms). 미리보기 창이 숨겨져 requestAnimationFrame fps를 못 재서 그리기 시간으로 비교. 태양광 판을 윗면만 그리게 줄임(14.8ms → 10.3~11.8ms).
